What Changes

The current WebGL hero shader is replaced with pretext's particle-driven ASCII system. Floating attractors create organic blob shapes rendered as proportional ASCII characters — each glyph measured by pretext for precise width fitting. The DDD logo emerges from and dissolves into the particle field.

Why It Works

  • Directly upgrades existing ASCII aesthetic
  • Variable weight + italic creates depth
  • Particle physics feel organic, not static
  • Mint-on-dark palette preserved perfectly
  • Mouse interaction moves attractors

Complexity

Recommended Hero only ~200 LOC

What Changes

The #idea project description section becomes a multi-column editorial layout. Text flows around floating colored orbs using pretext's layoutNextLine() with variable-width lines. Pull quotes emerge as highlighted blocks. Text reflows live as orbs drift.

Why It Works

  • Makes the manifesto feel alive, not static
  • Orbs add warmth to the dark palette
  • Pull quotes create visual hierarchy
  • Text reflow is mesmerizing on scroll
  • Zero DOM measurement = butter smooth

What Changes

The sets section + details grid merge into a single masonry layout where video cards, text manifesto blocks, info cards, and gallery images coexist. Pretext predicts card heights without DOM reads, enabling smooth virtualized scrolling and real-time layout updates.

Why It Works

  • Unifies fragmented sections into one flow
  • Scales naturally as episodes are added
  • Virtualized = fast with many items
  • Text cards shrink-wrap perfectly
  • Retains scanlines, REC badges, etc.
